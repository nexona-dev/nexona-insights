# Nexona Insights - E-commerce Sales Data Cleaning & Reporting

A Python data analysis project that cleans messy e-commerce sales data, performs exploratory analysis, and generates visual reports.

## Features
- Cleans inconsistent customer names, missing values, and duplicates
- Calculates total sales per order
- Analyzes sales by region
- Generates bar chart visualization
- Exports cleaned data to CSV

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Run: `python insights.py`

## Tech Stack
Python, Pandas, Matplotlib, Seaborn
